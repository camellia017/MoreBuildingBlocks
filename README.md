# MoreBuildingBlocks v0.0.3

为原版建筑方块补上衍生物：**陶瓦家族的楼梯与台阶**、**可以竖直放置的原版半砖**、**八分块**（1/8 大小的新方块），以及**能连出拐角的玻璃板、铁栅栏与铜栅栏**。

- 适用于 Minecraft **26.3**（Fabric）
- 需要 Fabric Loader 0.19.5+、[Fabric API](https://modrinth.com/mod/fabric-api)、Java 25
- 当前版本 **0.0.3**

## 更新

1. 修改了玻璃板的连接逻辑，现在它们更加贴合原版。
2. 重做了玻璃板与栏杆（铁栏杆、铜栏杆）的碰撞箱与纹理：现在他们的观感更加整齐。
3. 修复了竖台阶的放置逻辑，现在对着竖台阶的露出面放置方块不会再将竖台阶替换了。
4. 降低了加载耗时与内存占用。
5. 许可证改为 Apache License 2.0。

## 下载与安装

1. 到 [Releases](https://github.com/camellia017/MoreBuildingBlocks/releases) 下载 `morebuildingblocks-0.0.3.jar`（**不要**下 Source code 压缩包）
2. 装好 Fabric Loader 与 Fabric API，把 jar 放进 `.minecraft/mods/`

## 内容

| 新增 | 数量 |
|---|---|
| 陶瓦、染色陶瓦、带釉陶瓦的楼梯与台阶 | 33 种基础方块 → **66 个方块** |

## 配方

全部在**切石机**或**工作台**里完成，不需要新材料：

- **八分块**：切石机里 1 个基础方块 → **8 个**八分块（例：金合欢木板 → 8 个金合欢木八分块）。
- **楼梯 / 台阶**：工作台 6 个方块 → 4 个楼梯、3 个方块 → 6 个台阶；也能用切石机切（1 个方块 → 1 个楼梯或 2 个台阶）。
- **竖直半砖**：不用合成，直接拿原版半砖竖着放即可。

## 放置逻辑

- **八分块**：点哪一小格就放进哪一格，一格里最多 8 个；同一格不接受第二种材质，点在格缝上不会消耗物品。
- **竖直半砖**：点方块的**整面**补成整块；点**朝向自己的那一面**按点击的上/下位置放半格；点**薄边**则顺着相邻格继续排下去。
- **玻璃板 / 栏杆**：连接由模组自动处理，**只针对 `minecraft:` 命名空间**的玻璃板与栏杆——其它模组的栏杆保持原版行为。

## 已知限制

- 竖直半砖通过 Mixin 扩展原版 `SlabBlock`，与同样改动 `SlabBlock` 状态属性的模组可能冲突。
