# MoreBuildingBlocks

为陶瓦家族补上楼梯与台阶，让**所有原版半砖**都能竖直放置，并为 129 种材质加上**八分块**。

- 适用于 Minecraft **26.3**（Fabric）
- 需要 Fabric Loader 0.19.5+、[Fabric API](https://modrinth.com/mod/fabric-api)、Java 25

## 下载与安装

1. 到 [Releases](https://github.com/camellia017/MoreBuildingBlocks/releases) 下载 `morebuildingblocks-<版本>.jar`
2. 装好 Fabric Loader 与 Fabric API，把 jar 放进 `.minecraft/mods/`
3. Release 页里的 `Source code (zip/tar.gz)` 是源码归档，**不能**直接装进游戏

## 内容

| 新增 | 数量 |
|---|---|
| 陶瓦、染色陶瓦、带釉陶瓦的楼梯与台阶 | 33 种基础方块 → **66 个方块** |
| 可以竖直放置的原版半砖（不新增方块） | **101 个**（含羊毛、混凝土、铜半砖） |
| 八分块（1/8 大小的新方块，一格里最多放 8 个） | 33 个陶瓦族 ＋ 96 个原版材质 → **129 个方块** |
| 创造模式 **MoreBuildingBlocks** 标签页 | **195 个物品**（楼梯 → 半砖 → 八分块） |

- 配方与原版一致：工作台 6 方块 → 4 楼梯、3 方块 → 6 台阶；33 种基础方块都能用切石机切出楼梯与台阶。
- 不新增纹理文件，全部复用原版纹理；带釉陶瓦的花纹按原版逐面旋转表生成，切角后不会错位。
- 八分块只用切石机：1 个基础方块 → 8 个八分块，没有工作台配方；物品图标是该方块 x-、y-、z- 角上的那一个八分块，只有原方块的 1/8 大小，纹理按该八分位裁下来、不会被拉伸，图标摆在该格中线上（水平居中、仍在下半部分）。
- 放八分块时按点击位置决定放在哪一份：点在格子中间的接缝上就补进同一格，点在格界上就放进相邻那一格；
  只有带釉陶瓦这类花纹本身按朝向排布的方块，一格里 8 个八分块的纹理朝向才会与第一个一致（木板、铜块等原版不旋转的方块跟着原版不旋转）；
  用台阶/楼梯或用别种材质的八分块都抢不走已经在用的格子。
- 挖掉含有八分块的一格，会掉出该格里的全部八分块。
- 八分块同时出现在原版的「建筑方块」与「染色方块」标签页里，插在对应方块自己的楼梯、半砖之后。
