# MoreBuildingBlocks

为原版建筑方块补上衍生物：**陶瓦家族的楼梯与台阶**、**可以竖直放置的原版半砖**、**八分块**（1/8 大小的新方块），以及**能连出拐角的玻璃板、铁栅栏与铜栅栏**。

- 适用于 Minecraft **26.3**（Fabric）
- 需要 Fabric Loader 0.19.5+、[Fabric API](https://modrinth.com/mod/fabric-api)、Java 25
- 当前版本 **0.0.2**

## 下载与安装

1. 到 [Releases](https://github.com/camellia017/MoreBuildingBlocks/releases) 下载 `morebuildingblocks-<版本>.jar`
2. 装好 Fabric Loader 与 Fabric API，把 jar 放进 `.minecraft/mods/`

## 内容

| 新增 | 数量 |
|---|---|
| 陶瓦、染色陶瓦、带釉陶瓦的楼梯与台阶 | 33 种基础方块 → **66 个方块** |
| 可以竖直放置的原版半砖（不新增方块） | **101 个**（含羊毛、混凝土、铜半砖） |
| 八分块（1/8 大小的新方块，一格里最多放 8 个） | 33 个陶瓦族 ＋ 100 个原版材质 → **133 个方块** |
| 能连出拐角的玻璃板、染色玻璃板、铁栅栏与铜栅栏（不新增方块） | **26 个原版方块** |
| 创造模式 **MoreBuildingBlocks** 标签页 | **199 个物品**（楼梯 → 半砖 → 八分块，八分块按材质与颜色分组排列） |

### 玻璃板与栏杆

玻璃板、染色玻璃板、铁栅栏与 8 档铜栅栏各被拆成 **12 个部件**：四个方向各分上下两半的竖直面片（各 2 像素厚），加上四个角上、位于中间高度的 8×8 水平角片。

- 邻居是玻璃板/栏杆、墙，或者朝这一格的完整实心面时，对应方向的部件就会出现；两个方向的连接在拐角相遇时角片点亮，所以拐弯、十字和整面玻璃墙都能连成一片。
- 12 个部件里有 8 个是新开关，**默认全关**：此时外观与原版一模一样，老存档和没改装过的玻璃板不受影响。
- 26.3 里普通玻璃板、16 种染色玻璃板、铁栅栏和 8 档铜栅栏同属一个父类，这一套对它们同时生效；铜栅栏风化、涂蜡换块后部件状态保留。
- 不新增方块、物品、配方与掉落表，全部是原版方块的新状态。

### 八分块

8×8×8 的小方块，一格里有 8 个独立位置，最多放 8 个；8 个全开就是一个完整方块。

- 对着方块的一个面放置时，落点决定它占这一格的哪一份；点到接缝时放进同一格，点到格界时放进相邻格。
- 一格里只能有一种材质的八分块；用台阶、楼梯物品点八分块，或用异类材质的八分块物品点已有八分块的格子，都会被拒绝。
- 带釉陶瓦的八分块按该格第一个八分块的朝向旋转花纹，其余 117 种材质不旋转；物品图标是方块角上那一份八分块（原方块的 1/8 大小）。
- 挖掉含八分块的一格，会掉落该格里的全部八分块。

### 竖直半砖

原版半砖多了一个「竖直」状态：立起来时占满高度、只占半格深度，两个竖直半砖对着放可以合成一个完整方块。原版 101 种半砖全部适用，不新增方块。

## 配方

- 工作台：6 方块 → 4 楼梯、3 方块 → 6 台阶；33 种基础方块都能用切石机切出楼梯与台阶。
- 八分块暂时只可用切石机合成：1 个基础方块 → 8 个八分块，没有工作台配方。
- 玻璃板、铁栅栏与铜栅栏不加配方，也不新增掉落。
- 不新增纹理文件，全部复用原版纹理；带釉陶瓦的花纹按原版逐面旋转表生成，切角后不会错位。

## 已知限制

- 玻璃板与栏杆的 8 个新开关不随结构方块的旋转、镜像一起变化。
